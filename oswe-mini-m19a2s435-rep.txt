## UI flow mapping (load → render → interact → submit)
1. Load:
   - `index.html` loads `src/main.tsx`, mounts `App`.
   - `OnboardingWizard` loads, reads mock API (`mocks/mock_api.json`) to prefill profile / handbook.
   - `UIEventLogger.createSessionId()` creates unique `sessionId` `sid_...`.
2. Render:
   - `Header` is sticky at `top: 0`.
   - `.content` is padded: `padding-top: calc(var(--header-height) + 1rem)` (fixes header overlap).
   - `.footer` is sticky at bottom: `position: sticky; bottom: 0;`.
   - CTA anchored above footer: `.anchor-cta { position: fixed; bottom: calc(var(--footer-height) + env(safe-area-inset-bottom) + 8px) }` (fixes mobile Safari overlay).
   - The handbook uses `react-markdown` + `rehype-sanitize` to prevent raw HTML from rendering.
3. Interact:
   - Step navigation via Next & Back buttons and keyboard (`Enter`, arrows).
   - Focus management: `mainRef.current?.focus()` on step change, `aria-live="polite"` to notify screen readers.
   - The `UIEventLogger` logs `page.load`, `step.change`, `cta.click`, `form.submit` to console and localStorage (`ui_events_<sessionId>`) with no PII.
4. Submit:
   - `Submit` triggers `logEvent('form.submit')` and shows mock confirmation.

## Root-cause evidence and mitigation (what I collected)
- Evidence capture:
  - `scripts/generate_evidence.js` writes `docs/dom_snapshot_1280.html` and `docs/css_vars.json`.
  - `tests/run_suite.js` generates screenshots in `docs/screenshots/*.png` and writes `docs/ui_test_results.json`.
- Root cause & remediation:
  - Overlap (13" laptop): header was sticky with content not accounting for header height. Fix: `.content { padding-top: calc(var(--header-height) + 1rem) }`.
  - Mobile Safari CTA hidden by sticky footer: content needed bottom padding + anchor CTA must respect `safe-area` and footer height. Fix: `.content { padding-bottom: calc(var(--footer-height) + env(safe-area-inset-bottom)); }` and `.anchor-cta { position: fixed; bottom: calc(var(--footer-height) + env(safe-area-inset-bottom) + 8px) }`. CTA is clickable and visible across viewports.
  - Markdown raw HTML in dark mode: fallback was rendering raw HTML (script). Fix: switch to `react-markdown` + `rehype-sanitize`. This strips malicious HTML like `<script>` and inline event handlers.
  - Accessibility: provided ARIA roles (`role="banner"`, `role="main"`), `aria-roledescription` for the wizard, keyboard handlers, and a visible focus outline CSS.

- Content padding & CTA anchoring (fix overlap & CTA lost):
