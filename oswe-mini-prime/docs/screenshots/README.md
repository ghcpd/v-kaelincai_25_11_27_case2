Screenshots and traces created by the Playwright test harness. These files are:

- desktop_layout.png (or svg if placeholder)
- laptop13_layout.png
- mobile_safari_cta.png
- dark_mode_markdown.png
- keyboard_navigation.png
- layout_trace_<scenario>.json — DOM/CSS bounding box information for the header/content
- a11y_snapshot_<scenario>.json — Accessibility snapshots captured by Playwright

If running tests, look for newly created files under this directory.
