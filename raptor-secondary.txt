## 🧭 UI flow & root causes
1. **Flow:** load → theme init → steps render → interact (nav/CTA) → submit (simulated async) → logs emitted.
2. **Root causes fixed:**
   - **Header overlap (13″ laptops):** fixed header lacked reserved space; content now uses `min-height: calc(100vh - var(--header-height) - var(--cta-height))`.  
     - Evidence: `docs/screenshots/laptop13_layout.json` (header bottom < content top).
   - **CTA hidden on mobile Safari:** sticky footer covered CTA; CTA now sticky with `safe-area-inset-bottom` padding and content bottom padding for clearance.  
     - Evidence: `docs/screenshots/mobile_safari_layout.json`.
   - **Markdown raw HTML in dark mode:** default renderer lacked raw+sanitize and theme tokens; added `react-markdown` with `rehype-raw/rehype-sanitize` and theme CSS variables.  
     - Evidence: `docs/screenshots/markdown_dark.png`.

---

## 🔧 Fixes implemented
- **Responsive layout:** Breakpoints at 1280/1024/768; sticky header/footer; CSS vars `--header-height`, `--cta-height`.
- **CTA anchoring:** `.cta-bar` sticky bottom with safe-area padding; main content padded to avoid overlap.
- **Markdown rendering:** `react-markdown` + `remark-gfm` + `rehype-raw/sanitize`; themed `.markdown-body`.
- **Accessibility:** Skip link, focus management on step change, ARIA labels, keyboard nav (Arrow keys), `aria-live` updates.
- **Structured logging:** `createUiLogger` emits `load_success`, `theme_change`, `navigation`, `step_view`, `submit_*`, `keyboard_navigation` to `window.__UI_LOGS__` (PII redacted).
